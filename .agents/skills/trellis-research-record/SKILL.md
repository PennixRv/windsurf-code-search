# Trellis Research Record

Keep task-relevant evidence in the active task rather than only in session context.

1. Confirm the active task, actual modification target, and authoritative source.
2. Before changing scope or ending the work, record verified facts with evidence locators in that task's `research/` directory or another appropriate task artifact. Keep candidates and uncertainty separate from facts, and state one bounded next action when needed.
3. A subnode report is a candidate artifact. The coordinator verifies it and records the resulting conclusion; this Skill does not accept reports, alter task lifecycle, create a handoff, or create a second ledger.

Do not create a record for routine navigation, temporary tool output, waits, compaction, or observations with no task value.
